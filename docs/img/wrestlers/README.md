# Wrestler portraits

Put a picture here (webp or jpg, about 480 px wide, tall is fine) and add a line to `images.json` with the wrestler's ring name in lower case:

```json
{
  "hardbody harrison": "hardbody.webp",
  "paco rodriguez": "paco.webp"
}
```

The picture shows on the Superstars tiles, the Champions cards, the match header cards, the wrestler's profile and the CEO roster. A wrestler without a picture keeps the blue star tile.
